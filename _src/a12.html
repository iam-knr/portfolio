Why I built a desktop buddy

My day is split between ad accounts, client calls, classes and code. Tasks slip. A tab stays open for three days and the thing it was for never gets done.

I wanted something that sat on my screen, not in a browser tab I would forget. It had to remind me, hold my to-do list, and stay out of the way. So I wrote a small Python script that started with my computer. That was the first version of Shika.

It was a hobby project. Nobody asked for it. I used it on my own computer, and I kept adding things I wanted. Later I put it on GitHub with versions for Linux, macOS and Windows, and gave it a landing page.

I call it a desktop buddy, not a tool. The default buddy is named Shika. There are 15 pet companions in all, and you can switch between them.

What Shika AI does today

  • Voice typing in any app. Hold a key, talk, release. Your words land where your cursor is: email, a document, a chat box, an ad platform.
  • Cleanup of what you said. Spoken sentences are messy. Shika tidies them so you edit less.
  • Reminders and tasks. The things you tell yourself you will do later, kept where you will see them.
  • Sticky notes. Short notes that stay on the screen.
  • A focus timer. One block of work with no switching.
  • 15 pet companions. A small character that lives on your screen.

It is free and the code is on GitHub as desktop-buddy. You can read it, change it or ask for a feature.

Why speech to text runs on your machine

I work with client ad accounts and campaign numbers. I did not want my dictation going to a server somewhere to be turned into text.

So speech to text and cleanup in Shika run on your own computer with local AI models. Your voice does not leave the machine. That is the main reason I built voice typing myself instead of using a cloud service.

There is a cost. Local models use your computer's memory and processor, and they may be a little slower or less exact than the biggest cloud models. For notes, emails and first drafts, I find it is a fair trade. If you need perfect transcripts of a noisy room, use a service built for that.

What a hobby project taught me about AI agents

Most of my consulting work is about agentic AI: software that takes a goal, plans steps and uses tools. Shika is not that. By the simple test in my guide, you ask who decides the next step after you give the instruction. With Shika, you do. So it is a helper, and I would not call it an agent.

But building it taught me three things I now tell clients.

  1. Start with one daily irritation. My problem was forgotten tasks, not "productivity". A narrow problem is much easier to solve than a broad one.
  2. Use it yourself before anyone else does. You find the real problems when the tool sits on your own screen all day. Teams that never use their own agents ship those problems to customers.
  3. Keep the private part local. Decide early which data must not leave the machine. It is much harder to add that rule later.

The step from a helper to an agent is a small one in code and a large one in trust. A reminder app that nags you is harmless. An agent that sends emails or changes a bid needs limits, a draft mode and a person who approves. I cover that in agentic AI in marketing and in the guide for Indian SMEs.

How marketers can use a desktop buddy

You do not need to be a developer. These are the uses I see for a marketing team.

  • Briefs and reports by voice. Say the first draft of a client update. Edit it once. This often takes less time than typing it.
  • Daily checks as reminders. "Check ad accounts at 10", "reply to leads at 4". Small, fixed, hard to forget.
  • Focus blocks for deep work. A campaign audit needs an hour without chat. A timer helps you protect it.
  • A list of jobs to hand off later. When a reminder is the same every day, ask if a workflow could do it. Tools like n8n can run that job and ping you only if something looks wrong.

That last point is where a hobby tool and client work meet. The repeat jobs you write down in a task list are the best candidates for AI automation. I use the same idea when I plan an agent for a business.

Frequently asked questions

What is Shika AI?

Shika AI is a free, open source desktop buddy for Linux, macOS and Windows. It types what you say into any app, and it keeps reminders, tasks, sticky notes and a focus timer. A small pet companion lives on your screen.

Is Shika AI free?

Yes. It is free and open source. The code is on GitHub as desktop-buddy.

Does voice typing send my audio to the cloud?

No. Speech to text and cleanup run on your own machine with local models, so your voice stays on your computer.

Which operating systems does it support?

Linux, macOS and Windows.

Why did you call it a desktop buddy and not an assistant?

Because it started as a small companion that reminds me of my tasks. A buddy that sits on your screen and helps is closer to what it does than a full assistant that makes decisions for you.

Is Shika an AI agent?

No. You decide each step, so it is a helper. An agent plans and acts toward a goal by itself. My guide What is agentic AI explains the difference.
