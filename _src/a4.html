What is n8n?

n8n (said "n-eight-n") is a workflow automation tool. You build flows by dragging nodes onto a canvas and connecting them. One node reads a new lead from a form. The next looks it up in a CRM. The next sends a message. Each node does one job and passes its output to the next.

Three traits make it stand out for me:

  • You can self-host it. Your data stays on your own server. That matters for lead data and for clients with privacy rules.
  • You can see every step. You click a node and read exactly what went in and what came out. Debugging an agent without that is painful.
  • It can run code. When a node does not exist, you write a few lines of JavaScript or call any API directly.

Check n8n's current license and plan terms on its own site before you commit. It uses a source-available style license, not a classic open source one, and plans change.

How AI agents work inside n8n

n8n has an AI Agent node. You attach four things to it.

  1. A chat model. The brain. You choose a provider and add your key.
  2. Memory. So the agent remembers earlier messages in a conversation.
  3. Tools. Other nodes the agent may call, such as "search CRM", "send WhatsApp template" or "read Google Sheet".
  4. A system message. Your written instructions: role, rules, what not to do.

When the workflow runs, the agent reads the input, decides which tool to call, reads the result and repeats until it has an answer. This is the loop from what is agentic AI, built with blocks.

n8n and MCP

n8n supports MCP in two directions.

  • As a client. An MCP client tool node lets your agent use tools from any outside MCP server.
  • As a server. An MCP server trigger node exposes selected workflows as tools. A chat app or another agent can then call "create lead" or "get weekly ad report", and n8n runs the flow.

The second one is the useful trick. You build and test a workflow the usual way, then give it to an agent as a single safe tool. The agent cannot do more than that workflow allows. That is the permission control I want.

6 marketing workflows to build in n8n

1. Instant lead response agent

Trigger: new lead from a Meta lead form or website form. Steps: check for duplicate in CRM, ask the agent to classify intent from the answers, create the record, send the first WhatsApp template, notify the sales owner. Add a rule: if the phone number is invalid, send an email instead.

2. Daily ad account watcher

Trigger: every morning. Pull yesterday's cost, clicks and conversions per campaign. The agent compares them with your targets and writes three lines: what is wrong, how big it is, what to check first. It posts to your team chat. It does not change anything.

3. Search terms cleaner

Pull the search terms report weekly. The agent groups irrelevant terms with a reason for each. A person approves the list in a sheet, then a second flow adds the negatives.

4. Weekly client report

Collect numbers from ads, analytics and CRM. The agent writes a plain language note. A sheet stores the numbers, so every figure can be checked.

5. Content brief builder

Give a keyword. The workflow fetches the top pages, the agent lists headings, questions and gaps, and drops a brief into your docs folder.

6. Review and mention monitor

Check review sites and social mentions daily. The agent tags sentiment, drafts replies and sends them for approval.

A starter build you can finish in an afternoon

Take workflow 2, the ad account watcher.

  1. Add a Schedule trigger for 8 am.
  2. Add a node that pulls yesterday's data from your ad platform. Start with a CSV or sheet if the API is hard.
  3. Add the AI Agent node with a chat model. Write the system message: "You review ad performance. Compare each campaign to its target in the sheet. Report only what is off by more than 20 percent. Show the number and its source. Never suggest changes you cannot support with data."
  4. Give it one tool: read targets from a sheet.
  5. Send the output to your team chat.
  6. Run it on last week's data and check each claim by hand.

Where n8n falls short

  • You own the upkeep. Self-hosting means updates, backups and uptime are your job.
  • Large agent systems get hard to read. A canvas with 80 nodes is a maze. Split into small workflows.
  • Agent behavior needs testing. The same input may give slightly different output. Test with many sample cases.
  • Credentials sprawl. Keep keys in the credential store, never in node text.
  • Platform limits. Ad platforms limit API access and require approvals. Plan for that before promising a client.

Safety settings I always use

  • A maximum step count on every agent.
  • Read-only credentials unless a write is the whole point.
  • A human approval step before spend changes and customer messages.
  • An error workflow that alerts me when any run fails.
  • A log table with time, input, tool called, output.

Should you hire someone to build it?

If the task is simple, learn it yourself. n8n is friendly enough. If the flow touches money, customer data or many systems, a specialist saves you from expensive mistakes. I wrote a checklist for that choice in how to choose an agentic AI consultant in India.

Frequently asked questions

What is n8n used for?

n8n is used to automate work between apps, such as moving leads from forms to a CRM, sending messages, building reports and running AI agents that decide between tools.

Is n8n free?

You can self-host it at no license cost under its terms, but you pay for the server and your time. Its cloud service is paid. Check the current terms on the n8n site.

Is n8n better than Zapier?

For control, self-hosting and custom logic, n8n is stronger. For the quickest simple automations with the easiest setup, Zapier is often simpler. The right choice depends on the job.

Can n8n build AI agents?

Yes. Its AI Agent node connects a chat model, memory and tools so the model can choose actions across several steps.

Does n8n support MCP?

Yes. It can call outside MCP servers from an agent and can expose its own workflows as an MCP server for other AI apps to use.

Do I need to code to use n8n?

Basic flows need no code. Complex flows are easier if you can read a little JavaScript and understand APIs.
